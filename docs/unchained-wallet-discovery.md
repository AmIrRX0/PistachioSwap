# Pchained Wallet Discovery

PistachioSwap derives wallet-token coverage from `ACTIVE_TOKEN_DISCOVERY_CHAINS` in the API token-discovery registry. Do not maintain a separate active-chain list.

Provider order for each wallet request:

1. self-hosted Pchained, when the chain has a verified EVM coinstack and a configured local endpoint
2. existing wallet-token providers: Alchemy Portfolio, legacy Alchemy/Moralis/RPC paths
3. persisted curated fallback-token catalog, including native assets

Pchained, the fallback token catalog, and Gas Assist sponsorship allowlists are separate trust domains. A token discovered by Pchained or present in the fallback catalog is not automatically authorized for sponsorship, approvals, routing, or execution.

## Local Environment

```dotenv
UNCHAINED_ENABLED=true
UNCHAINED_REQUEST_TIMEOUT_MS=8000
UNCHAINED_HTTP_URLS_JSON={"56":"http://127.0.0.1:3156"}
UNCHAINED_BNB_INDEXER_URL=https://deep-index.moralis.io/api/v2.2
UNCHAINED_BNB_INDEXER_API_KEY=
UNCHAINED_BNB_RPC_URL=
UNCHAINED_BNB_RPC_API_KEY=
UNCHAINED_BNB_WEBHOOK_URL=
```

Localhost HTTP is accepted. Non-localhost HTTP remains rejected unless `UNCHAINED_ALLOW_INSECURE_HTTP=true` is explicitly set for a non-production local experiment.

## Verified Pchained Coinstacks

Pinned source: `https://github.com/parsij/Pchained.git` at standalone commit `0d9cf6682b329b2b14a8959400a25720a77247e0`.

Pchained preserves the compatible Unchained runtime interfaces used by PistachioSwap. The current local compose enables BNB Chain first through `node/coinstacks/bnbsmartchain`. The BNB API listens inside the container on port `3000`, exposes `/health`, and serves `GET /api/v1/account/{pubkey}` with `balance`, `pubkey`, and `tokens[]` fields. It uses Moralis wallet indexing and a BSC RPC endpoint; it does not require running a full BSC node.

## Manual Commands

```bash
pnpm unchained:print-start-commands
pnpm unchained:config:check
pnpm unchained:status
pnpm unchained:bnb:config:check
pnpm unchained:bnb:up
pnpm unchained:bnb:status
pnpm unchained:bnb:smoke
pnpm unchained:bnb:logs
pnpm unchained:bnb:down
```

`pnpm unchained:bnb:up` clones the pinned standalone Pchained source into `.unchained/Pchained`, checks out the exact verified commit, builds the local Node image, starts only the BNB API container, and waits for Docker health with a finite timeout. The generated `.unchained/bnbsmartchain.env` is local-only and ignored by git.

Required credential variable names for BNB:

- `MORALIS_API_KEY` or `UNCHAINED_BNB_INDEXER_API_KEY`
- `BSC_RPC_URL` with a final path key that can be split, or both `UNCHAINED_BNB_RPC_URL` and `UNCHAINED_BNB_RPC_API_KEY`
- optional `UNCHAINED_BNB_INDEXER_URL`
- optional `UNCHAINED_BNB_WEBHOOK_URL`

Common errors:

- `connection-refused`: no container is listening on the configured localhost port.
- `missing configuration`: a required variable name above is absent or empty.
- `schema-mismatch`: the endpoint responded, but not with the expected account schema.
- `wallet-address-mismatch`: `pubkey` did not canonicalize to the requested EVM address.

Setting `UNCHAINED_HTTP_URLS_JSON` does not start a coinstack. A URL is valid only after `pnpm unchained:bnb:smoke` returns HTTP 200 and confirms the account schema.

## Hidden Tokens

Pchained confirms balances, not trust. Exact `chainId + lowercase contract address` identity is joined to trusted catalog metadata. Unknown, malformed, unverified, or provider-confirmed spam holdings remain recoverable in Hidden tokens and do not contribute to portfolio totals.
